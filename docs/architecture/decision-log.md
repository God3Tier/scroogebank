# Target architecture: decision log

> **Status:** Accepted target architecture (2026-11-01). **Owner:** Neo Jia Wen. **Last updated:** 2026-11-01.  
> Drafted with AI assistance (Claude Code) from the team's architecture document. Verify AWS pricing, limits and service behaviour against official AWS documentation before accepting.  
> Part of the [target architecture](system-overview.md); each decision is recorded as an ADR in the [ADR index](../adr/README.md), which gives its status.

Every major decision in the target architecture, with what was chosen and what was not. Details are in the linked sections; each decision is recorded in the ADR in the last column.

| Cognito trigger runtime | Plain Java 25 on Lambda at 1,769 MB (a full vCPU; measured cold start about 0.5 s), sending within 3 seconds | Java at 256–512 MB: 1.9–4 second cold starts leave little time to retry within Cognito's 5 seconds.
